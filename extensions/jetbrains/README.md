# Astrovox AI - JetBrains Extension

## Features

- AI chat in tool window
- Code explanation
- Test generation
- Refactoring suggestions

## Installation

1. Open Settings -> Plugins
2. Search for "Astrovox AI"
3. Click Install

## Usage

- Open View -> Tool Windows -> Astrovox Chat
- Select code and right-click -> Astrovox -> Explain
- Use keyboard shortcut `Ctrl+Shift+A`

## Configuration

Settings -> Tools -> Astrovox AI

- API Key: Your Astrovox API key
- Model: gpt-4 (default)
- Temperature: 0.7
