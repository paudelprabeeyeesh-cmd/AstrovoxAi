# Astrovox AI - Astrovox Extension

## Features

- Chat with AI from any webpage
- Explain selected text
- Summarize pages
- Quick access sidebar

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select the `extensions/chrome` directory

## Usage

- Click the extension icon to open the sidebar
- Select text and right-click to explain
- Use the chat interface to ask questions

## Permissions

- `storage`: Save API key and settings
- `activeTab`: Access current tab content
- `contextMenus`: Right-click menu for explain feature
