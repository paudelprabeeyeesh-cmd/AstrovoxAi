# ASTROVOX AI

Master software engineering checklist and folder structure for the AstrovoxAI platform.

## Structure

| Folder | Purpose |
|--------|---------|
| 01_PRODUCT_FRONTEND | Web, desktop, mobile, extensions, design system |
| 02_PLATFORM_BACKEND | API, auth, memory, agents, tools, business logic |
| 03_AI_RESEARCH | Foundation models, post-training, alignment, evaluation |
| 04_INFERENCE_INFRASTRUCTURE | Serving engines, optimization, model router |
| 05_DATA_PLATFORM | Ingestion, processing, storage, streaming |
| 06_SAFETY_AND_ALIGNMENT | Input/output safety, red teaming |
| 07_SECURITY | App sec, infra sec, IAM, encryption, compliance |
| 08_DEVOPS_SRE_PLATFORM | Docker, K8s, CI/CD, observability, SRE |
| 09_CLOUD_INFRASTRUCTURE | Compute, GPU, networking, storage, cost |
| 10_DATABASES_AND_STORAGE | SQL, vector, cache, search, graph, TSDB |
| 11_BUSINESS_SYSTEMS | CRM, billing, support, analytics, marketing |
| 12_ENTERPRISE | SSO, controls, support, professional services |
| 13_LEGAL_AND_COMPLIANCE | Corporate, product legal, IP, regulatory |
| 14_PEOPLE_AND_CULTURE | Recruiting, HR, culture, total rewards |
| 15_FINANCE | Accounting, FP&A, treasury, tax, IR |
| 16_DEVELOPER_RELATIONS | SDKs, docs, community, ecosystem |
| 17_GLOBAL_OPERATIONS | Regions, data residency, localization |
| 18_TESTING_AND_QUALITY | Unit, integration, E2E, AI eval, red team |
| 19_RESEARCH_LABS | Frontier, applied, safety, publications |
| 20_INTERNAL_TOOLS | Engineering, data, business tools |
| 21_INVESTOR_AND_STRATEGY | Corp dev, fundraising, market intel |
