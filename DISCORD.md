# Discord

Join the AstrovoxAI community on Discord for real-time chat, support, and discussions.

## Server

- **URL:** [discord.gg/astrovox](https://discord.gg/astrovox)
- **Topics:** General discussion, support, feature requests, SDKs, enterprise, marketplace
- **Code of Conduct:** Follow our [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md)

## Channels

| Channel | Purpose |
|---------|---------|
| #welcome | Introductions and onboarding |
| #announcements | Product updates and release notes |
| #general | General discussion about AstrovoxAI |
| #support | Technical questions and troubleshooting |
| #sdk-python | Python SDK discussions |
| #sdk-typescript | TypeScript SDK discussions |
| #sdk-go | Go SDK discussions |
| #sdk-java | Java SDK discussions |
| #sdk-rust | Rust SDK discussions |
| #enterprise | Enterprise features and inquiries |
| #marketplace | Model and plugin marketplace |
| #api-portal | API portal and key management |
| #billing | Billing and subscription questions |
| #feedback | Feature requests and feedback |
| #showcase | Show your projects built with AstrovoxAI |
| #off-topic | Non-technical discussion |

## Rules

1. Be respectful and constructive
2. No harassment, discrimination, or hate speech
3. No spamming or self-promotion
4. Use the appropriate channels
5. No sharing of API keys or credentials
6. Report issues via GitHub Issues, not Discord

## Support

- **Community Support:** #support channel
- **Enterprise Inquiries:** #enterprise channel or enterprise@astrovox.ai
- **Security Issues:** security@astrovox.ai
