# Contributing to AstrovoxAI

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/AstrovoxAi`
3. Create a branch: `git checkout -b feature/my-feature`
4. Make changes and commit: `git commit -am 'feat: add feature'`
5. Push: `git push origin feature/my-feature`
6. Open a Pull Request

## Development Setup

```bash
# Backend
cd 02-Backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
pytest

# Frontend
cd apps/web
npm install
npm run dev
```

## Code of Conduct

- Be respectful and inclusive
- Welcome newcomers
- Focus on constructive feedback

## Reporting Bugs

Please include:
- Steps to reproduce
- Expected vs actual behavior
- Environment details
- Logs/screenshots

## Feature Requests

Open an issue first to discuss proposed changes.

## Questions

Join our Discord or open a GitHub Discussion.
