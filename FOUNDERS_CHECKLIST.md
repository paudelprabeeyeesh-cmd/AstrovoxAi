# Founder's Morning Checklist

Print this. Stick it on your wall. Do it every morning before checking email.

```
[ ] 10 min: Run `python scripts/check_budget.py`
[ ] 10 min: Check /metrics and /usage on live URL
[ ] 20 min: Reply to every user message personally
[ ] 60 min: ONE task — ship, fix, or validate
[ ] 20 min: Update feedback.md + METRICS.md
[ ] 10 min: Commit + push
```

Rules:
- No new features without a real user request.
- No paid infra until 10 paying users.
- If cost per user > $0.50/day, stop and optimize.
- If no one pays after 10 conversations, change the problem.
