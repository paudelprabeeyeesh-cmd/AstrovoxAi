# ADR-007: Aligned Memory Arena and Pools

## Status
Accepted

## Context
Tensor workloads allocate many same-sized buffers. Naive allocation causes GC pressure and unaligned data that defeats SIMD.

## Decision
`tensor/memory` provides `AlignedAlloc` (cache-line aligned), a bump `Arena` for temporaries, fixed-size `Pool`s for reuse, a `ReuseRegistry` keyed by shape+dtype, copy-on-write buffers, and import handles for zero-copy interop.

## Consequences
- SIMD kernels always receive aligned data.
- Temporaries from arenas are reset, not freed, per plan step.
- Pools cap memory growth via explicit `Reset`.
