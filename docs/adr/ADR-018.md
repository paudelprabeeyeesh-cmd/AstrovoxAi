# ADR-018: Asynchronous Structured Logging

## Status
Accepted

## Context
The engine emits high-volume diagnostics; synchronous logging would stall hot paths, and unstructured text is hard to query.

## Decision
`internal/logger` writes JSON-structured records (level, timestamp, message, fields) through an async ring buffer. Dropping is explicit: when the buffer is full, records are counted and reported, never blocking the caller.

## Consequences
- Hot-path logging never blocks.
- JSON output integrates with log aggregators directly.
- Backpressure is visible via drop counters.
