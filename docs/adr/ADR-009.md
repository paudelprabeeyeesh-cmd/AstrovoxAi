# ADR-009: Broadcast Semantics for Elementwise Operations

## Status
Accepted

## Context
Elementwise ops on tensors of different shapes (e.g., (3,4) with (4,)) need NumPy-compatible broadcasting with validated, predictable rules.

## Decision
`tensor/broadcast` implements standard broadcasting: dimensions align from the right, size-1 dimensions expand, mismatches fail with an error. `BroadcastShapes`, `OutputShape`, `BroadcastStrides`, and `ExpandStrides` let kernels consume broadcast operands without materializing them.

## Consequences
- Broadcasting never allocates; expanded strides use 0.
- Shape errors surface before any computation begins.
- `Expand` produces read-only views by design.
