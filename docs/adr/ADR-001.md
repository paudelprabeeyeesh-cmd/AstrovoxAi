# ADR-001: Single Go Module Monorepo

## Status
Accepted

## Context
Astrovox spans a tensor engine, computational graph, autograd, compiler, kernels, runtime, CLI, and shared internal utilities. Organizing this as multiple modules or repositories would complicate refactoring and atomic commits.

## Decision
All Go code lives in one module, `github.com/astrovox/astrovox`, at the repository root. Public packages (`tensor`, `graph`, `autograd`, `compiler`, `kernels`, `runtime`) sit at the module root; private support packages live under `internal/`.

## Consequences
- Atomic cross-package refactors and commits.
- `internal/` enforces encapsulation for non-public APIs.
- Versioning is unified: the whole module ships as one release.
