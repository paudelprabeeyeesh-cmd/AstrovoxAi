# ADR-002: Zero External Dependencies for the Core Engine

## Status
Accepted

## Context
ML frameworks commonly pull in large dependency trees (BLAS bindings, serialization libs, CLI frameworks), which increases build times, supply-chain risk, and platform matrix complexity.

## Decision
The core engine (tensor, graph, autograd, compiler, kernels, runtime, and all `internal/` packages) uses only the Go standard library. `go.mod` carries an empty `require` block.

## Consequences
- Reproducible builds with no transitive dependency risk.
- SIMD, FFT, GEMM, and RNG are implemented in-house.
- Third-party integration is deferred to plugin packages and the CLI shell.
