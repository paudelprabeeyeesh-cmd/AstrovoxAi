# ADR-008: Odometer-Based Tensor Iteration

## Status
Accepted

## Context
Elementwise kernels must visit every element of arbitrarily strided tensors without per-element division/modulo overhead.

## Decision
`tensor/iterator` implements an odometer iterator: a coordinate counter with per-axis strides that advances in O(1) amortized time, plus a `Contiguous` detector so fast paths skip iteration entirely.

## Consequences
- Elementwise ops run at memory-bandwidth speed on contiguous tensors.
- Strided iteration has no inner-loop arithmetic beyond increment/carry.
- Reduction plans reuse the same iterator machinery.
