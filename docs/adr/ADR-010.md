# ADR-010: Computational Graph with Stable IDs and Tombstones

## Status
Accepted

## Context
Graph editing (remove node, remove edge, fuse ops) must not invalidate references held by other components, and cycles must be impossible.

## Decision
`graph.Graph` assigns monotonically increasing stable IDs to nodes and edges. Removal marks a tombstone flag instead of mutating slice indices, preserving ID stability. `AddEdge` tentatively inserts, runs a topological-sort cycle check, and rolls back on failure. Outputs are explicitly designated via `MarkOutput`.

## Consequences
- Handles remain valid across arbitrary edits.
- Cycle prevention is checked at mutation time, not execution time.
- Optimizers (constant folding, DCE, elementwise fusion) rewrite via rewire, never rebuild.
