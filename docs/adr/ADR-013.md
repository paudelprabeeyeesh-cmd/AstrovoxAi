# ADR-013: Blocked GEMM and Cache-Aware Kernels

## Status
Accepted

## Context
Matrix multiplication dominates engine runtime; naive triple loops thrash the CPU cache on large tensors.

## Decision
`tensor/math/gemm.go` implements cache-blocked GEMM with MC=96, NC=256, KC=256 tiles, correct leading-dimension handling, plus `MatMul`, `BatchMatMul`, and `MatVec` wrappers. Convolution auto-selects im2col+GEMM when the kernel is at least 3x3.

## Consequences
- GEMM is the single path used by MatMul, Conv2d (large kernels), and BatchMatMul.
- Block sizes are constants, tunable per architecture in one place.
- Small kernels use direct loops to avoid im2col overhead.
