# ADR-004: Tensor as the Core Data Abstraction

## Status
Accepted

## Context
Every engine component (graph ops, autograd, kernels, compiler) manipulates multi-dimensional numeric data. A single tensor abstraction avoids impedance mismatches between layers.

## Decision
`tensor.Tensor` is the universal data carrier: a Storage view defined by offset, shape, strides, and dtype, supporting zero-copy slicing, transposition, broadcasting, and typed accessors for all primitive dtypes from bool to complex128.

## Consequences
- All engine APIs accept/return `*tensor.Tensor`.
- Views are cheap; copies are explicit via `Clone`.
- Serialization, hashing, and equality are defined once on the tensor.
