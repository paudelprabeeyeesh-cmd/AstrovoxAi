# ADR-012: Kernel Registry with Runtime SIMD Detection

## Status
Accepted

## Context
Vectorized kernels must use the best available ISA (AVX2, Neon) without breaking portability or requiring build tags per target.

## Decision
`tensor/math` exposes a `Kernel` registry keyed by name and `SIMDFeature`. `detectFeature` probes the CPU at init (amd64 -> AVX2, arm64 -> Neon) and registers the best implementation; scalar fallbacks always register first. Dispatch picks the highest-capability registered kernel.

## Consequences
- One binary runs optimally across x86 and ARM.
- New ISAs are added by registering another kernel, no build changes.
- Correctness is guaranteed because scalar paths are the default.
