# ADR-003: Package Layout and Public API Surface

## Status
Accepted

## Context
The project needs a clear boundary between the public engine API and private implementation details, so downstream users depend on stable packages only.

## Decision
Public packages are top-level directories: `tensor` (with `math`, `memory`, `ops`, `reduce`, `broadcast`, `iterator`, `reshape`, `transpose` subpackages), `graph`, `autograd`, `compiler`, `kernels`, `runtime`, and `pkg/cli`. Everything else lives in `internal/` and cannot be imported externally.

## Consequences
- Go's `internal/` rule enforces the public/private boundary at compile time.
- Subpackages of `tensor` are public but versioned together with the parent.
