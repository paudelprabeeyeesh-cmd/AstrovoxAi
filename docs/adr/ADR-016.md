# ADR-016: Layered Configuration with Hot Reload

## Status
Accepted

## Context
The engine needs runtime-tunable settings from files, environment, and code, with a deterministic precedence and the ability to change settings without restart.

## Decision
`internal/config` layers sources: defaults < file (JSON or YAML-subset parser) < environment override. A ticker-based watcher reloads changed files and notifies subscribers. Validation runs before any reload is applied.

## Consequences
- Precedence is explicit and testable.
- Hot reload is opt-in per key via subscription.
- The YAML parser is a safe subset; no external parser dependency.
