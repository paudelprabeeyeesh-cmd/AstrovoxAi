# ADR-006: Zero-Copy Tensor Views

## Status
Accepted

## Context
Slicing, transposing, and reshaping tensors must be O(1) to support high-throughput pipelines; eager copying would dominate runtime.

## Decision
A Tensor is a (Storage, offset, shape, strides, dtype) tuple. `Slice`, `Transpose`, `Permute`, `Expand`, and `Reshape` (when contiguous) return new Tensors sharing the same backing Storage. Mutations through views affect the base; `Clone` breaks the link.

## Consequences
- Views keep a `base` reference so the Storage is never collected early.
- In-place ops on views are safe by construction.
- Serialization forces contiguity before writing.
