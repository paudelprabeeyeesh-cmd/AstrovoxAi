# ADR-017: Typed Error Taxonomy with Stable Codes

## Status
Accepted

## Context
Engine errors must be machine-classifiable (retry vs. fail vs. ignore) and stable across releases for automation and dashboards.

## Decision
`internal/errors` defines a typed error hierarchy with stable string codes (e.g., shape mismatch, allocation failure, cycle detected). Errors implement `Unwrap` for `errors.Is/As` interop while exposing `Code()` for fast classification.

## Consequences
- Callers branch on codes, not string matching.
- Codes are append-only; existing codes never change meaning.
- Wrapped standard errors remain compatible with the stdlib.
