# ADR-005: DType System with Promotion Rules

## Status
Accepted

## Context
Tensor operations mix dtypes (e.g., float32 + int64). Ad-hoc conversion rules cause silent precision loss and bugs.

## Decision
`tensor.DType` is a closed enum (Bool, Int8..Int64, Uint8..Uint64, Float16, BFloat16, Float32, Float64, Complex64, Complex128) with explicit `Promote` rules, `Cast` semantics, size predicates, and IEEE-754-correct Float16/BFloat16 bit conversion (round-to-nearest-even, subnormal handling).

## Consequences
- Binary ops promote operands deterministically.
- Float16/BFloat16 are stored as uint16 bit patterns, never native Go types.
- Unknown dtypes parse-fail explicitly instead of defaulting.
