# ADR-015: DAG-Based Task Scheduler

## Status
Accepted

## Context
Engine workloads are graphs of tasks with data dependencies; naive thread pools cannot respect ordering or maximize parallelism.

## Decision
`internal/scheduler` provides a `DAG` of tasks with topological ordering and cycle detection, `IndependentSet` batching, a `WorkerPool` with task-completion `Wait`, `PriorityQueue`, round-robin `LoadBalancer`, `DynamicScheduler`, `Heuristics` (criticality, parallelism width), and an `EventBus`.

## Consequences
- Execution order is derived from the DAG, not from submission order.
- `Wait` returns when outstanding tasks finish, not when workers stop.
- Heuristics estimate the achievable parallelism width per level.
