## Optimization Targets

1. Replace sync HTTP calls in async functions with `httpx.AsyncClient`
2. Add `asyncio.sleep` instead of `time.sleep`
3. Lazy-load heavy singletons (provider factory, embeddings client)
4. Add Redis response caching with TTL
5. Add SQLite connection pooling (`sqlite3` + `threading.local` or `aiosqlite`)
6. Add `__slots__` to hot dataclasses in `workflow_engine.py`
7. Replace large dicts with `functools.lru_cache` or bounded dicts
8. Add DB indexes for `chats.user_id`, `chats.conversation_id`, `messages.conversation_id`
9. Add response caching middleware
10. Add memory profiling hook in hot path
