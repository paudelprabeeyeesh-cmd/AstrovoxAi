# User Guide

## Getting Started

Welcome to AstrovoxAI. This guide walks you through using the platform.

## Account Setup

1. Navigate to the application
2. Click **Sign Up** and enter your email and password
3. Verify your email via the link sent to your inbox
4. Log in with your credentials

## Starting a Conversation

1. Click **New Conversation**
2. Select a model (GPT-4, Claude, Gemini, etc.)
3. Type your message and press Enter
4. View the AI response stream in real time

## Managing Conversations

- **Rename**: Click the conversation title to edit
- **Pin**: Keep important conversations at the top
- **Archive**: Hide conversations without deleting
- **Delete**: Permanently remove conversations

## Using Memory

AstrovoxAI remembers context across sessions:

1. Click the **Memory** icon in the sidebar
2. Add notes like "I prefer concise answers"
3. The AI uses this context in future conversations

## Switching Models

Click the model selector in the conversation header to switch between:
- OpenAI GPT-4
- Anthropic Claude
- Google Gemini
- Groq (fast inference)
- Ollama (local models)

## Voice Input

Click the microphone icon to speak your message. Supported languages:
- English
- Spanish
- French
- German

## File Attachments

Attach documents to conversations:
- PDFs
- Images
- Text files

The AI can analyze and reference these files.

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New conversation |
| `Ctrl+K` | Search conversations |
| `Ctrl+/` | Command palette |
| `Shift+Enter` | New line in message |

## Billing

- Free tier: 50 AI requests/day
- Pro tier: Unlimited requests, priority support
- Enterprise: Custom limits, SLA

View usage in **Settings → Billing**.
