# Glossary

Definitions of key terms used throughout Astrovox AI documentation.

## A

**Agent**
An autonomous AI entity that can perform tasks, use tools, and maintain state across interactions.

**API Key**
A unique identifier used to authenticate requests to the Astrovox AI API.

**Attention**
A mechanism in transformer models that weights the importance of different parts of the input when producing an output.

**Authentication**
The process of verifying the identity of a user or system.

**Authorization**
The process of determining if an authenticated user has permission to perform an action.

## B

**Backend**
The server-side application that handles API requests, business logic, and data persistence.

**Branching**
The ability to create alternative conversation paths from a single message to explore different AI responses.

**Burst**
The maximum number of requests allowed in a short time window for rate limiting.

## C

**Chat Completion**
The API endpoint that generates AI responses to user messages.

**Context Window**
The maximum number of tokens a model can process in a single request.

**Conversation**
A sequence of messages between a user and AI, stored with a unique identifier.

**Conversation History**
The collection of all messages in a conversation, used for context in AI responses.

**CORS**
Cross-Origin Resource Sharing, a mechanism that allows restricted resources on a web page to be requested from another domain.

**Crawl**
The process of automatically discovering and indexing web content for search or RAG.

## D

**Deployment**
The process of making an application available for use, typically on servers or cloud infrastructure.

**Diff**
The difference between two versions of a file, used in code reviews.

**Docker**
A platform for developing, shipping, and running applications in containers.

**Docker Compose**
A tool for defining and running multi-container Docker applications.

## E

**Embedding**
A numerical representation of text that captures semantic meaning, used for similarity search and RAG.

**Endpoint**
A specific URL where an API can be accessed.

**Environment Variable**
A dynamic value that can affect the way running processes behave on a computer.

**Evaluation**
The process of assessing AI model performance against benchmarks or human judgment.

## F

**FastAPI**
A modern, fast web framework for building APIs with Python 3.7+ based on standard Python type hints.

**Fine-tuning**
The process of further training a pre-trained model on a specific dataset to improve performance on a particular task.

**Frontend**
The client-side application that users interact with, built with React and TypeScript.

## G

**Generation**
The process of creating new content (text, code, images) using an AI model.

**Grafana**
An open-source platform for monitoring and observability.

## H

**HSTS**
HTTP Strict Transport Security, a security policy mechanism that helps protect websites against man-in-the-middle attacks.

**HTTPS**
Hypertext Transfer Protocol Secure, the secure version of HTTP.

## I

**Idempotency**
The property of certain operations that can be applied multiple times without changing the result beyond the initial application.

**Ingestion**
The process of importing data into a system for processing and storage.

## J

**JWT**
JSON Web Token, a compact, URL-safe means of representing claims to be transferred between two parties.

## K

**Knowledge Base**
A structured collection of information that can be queried by AI systems, often used with RAG.

## L

**Latency**
The time delay between a request and its response.

**LLM**
Large Language Model, a type of AI model trained on vast amounts of text data to generate human-like text.

**LLM Router**
A component that selects the optimal AI provider and model for a given request based on cost, speed, and capability.

**Load Balancer**
A device or software that distributes network traffic across multiple servers.

## M

**Markdown**
A lightweight markup language for creating formatted text.

**Memory**
The system's ability to remember information across conversations, including short-term context and long-term facts.

**Migration**
The process of moving data or applications from one environment to another.

**Model**
A specific AI implementation (e.g., gpt-4, claude-3-opus) with defined capabilities and pricing.

**Mermaid**
A JavaScript-based diagramming and charting tool that renders Markdown-inspired text definitions.

**Middleware**
Software that sits between the operating system and applications, or between client and server in web applications.

## O

**Observability**
The ability to measure a system's current state based on data it generates, such as logs, metrics, and traces.

**Ollama**
An open-source tool for running large language models locally.

**OpenAI**
An AI research laboratory consisting of the for-profit corporation OpenAI LP and its parent company, the non-profit OpenAI Inc.

**OWASP**
Open Web Application Security Project, a nonprofit foundation that works to improve the security of software.

## P

**Pagination**
The process of dividing content into separate pages, used for API responses with large datasets.

**PII**
Personally Identifiable Information, data that could be used to identify an individual.

**Plugin**
A software component that adds specific capabilities to a larger software application.

**PostgreSQL**
An open-source relational database management system.

**Pre-commit**
A Git hook framework that runs checks on code before it is committed.

**Provider**
An AI service provider (OpenAI, Anthropic, Gemini, Groq, Ollama) that offers language models.

**Prompt**
The input text provided to an AI model to generate a response.

**Prompt Engineering**
The practice of designing effective prompts to get desired outputs from AI models.

**Pydantic**
A data validation library for Python that uses type annotations.

**pgvector**
A PostgreSQL extension for storing and querying vector embeddings.

## R

**Rate Limiting**
The practice of limiting the number of requests a user or system can make in a given time period.

**RAG**
Retrieval-Augmented Generation, a technique that enhances AI responses by retrieving relevant information from a knowledge base.

**React**
A JavaScript library for building user interfaces.

**Redis**
An in-memory data structure store, used as a database, cache, and message broker.

**Redux**
A predictable state container for JavaScript apps.

**Refactor**
The process of restructuring existing code without changing its external behavior.

**Regression**
A bug that reappears after being fixed, or a degradation in performance.

**REST**
Representational State Transfer, an architectural style for distributed systems.

**RLS**
Row Level Security, a PostgreSQL feature that enables security at the row level.

**Router**
A component that directs API requests to the appropriate handler.

## S

**SAML**
Security Assertion Markup Language, an open standard for exchanging authentication and authorization data.

**Sandbox**
An isolated environment where code can be executed safely without affecting the main system.

**Schema**
The structure of a database, defining tables, columns, and relationships.

**SDK**
Software Development Kit, a collection of tools and libraries for building applications.

**Secret**
Sensitive information such as API keys, passwords, or certificates.

**Semantic Cache**
A cache that stores AI responses based on semantic similarity, allowing cache hits for similar queries.

**Server-Sent Events (SSE)**
A standard that enables servers to push data to clients over HTTP.

**Session**
A period of user interaction with an application, typically tracked via authentication tokens.

**Slack**
A business communication platform offering chat, channels, and integrations.

**SSO**
Single Sign-On, an authentication scheme that allows users to log in with a single ID to multiple applications.

**Streaming**
The process of sending data in continuous chunks rather than waiting for the complete response.

**Supabase**
An open-source Firebase alternative providing PostgreSQL database, authentication, and real-time features.

## T

**Tailwind CSS**
A utility-first CSS framework for rapidly building custom user interfaces.

**Tenacity**
A Python library for retrying code with configurable backoff strategies.

**Terminal**
A text-based interface for interacting with a computer.

**Testing**
The practice of verifying that software works as intended through automated and manual tests.

**Token**
A unit of text processed by a language model (roughly 4 characters or 0.75 words for English).

**Tool Use**
The ability of an AI agent to invoke external functions or APIs to accomplish tasks.

**Tracing**
The process of tracking requests as they flow through a distributed system.

**TypeScript**
A strongly typed programming language that builds on JavaScript.

## U

**Uvicorn**
A lightning-fast ASGI server implementation for Python.

## V

**Vector Database**
A database optimized for storing and querying high-dimensional vectors, used for similarity search in AI applications.

**Vercel**
A cloud platform for frontend frameworks and static sites, designed to work with headless content and commerce.

**Versioning**
The practice of assigning unique version numbers to software to track changes and compatibility.

## W

**WAF**
Web Application Firewall, a security layer that monitors and filters HTTP traffic.

**Webhook**
A method of augmenting or altering the behavior of a web page or application with custom callbacks.

**WebSocket**
A communication protocol that provides full-duplex communication channels over a single TCP connection.

**WCAG**
Web Content Accessibility Guidelines, recommendations for making web content more accessible.

**Workflow**
A sequence of connected steps or tasks that are executed in a specific order to accomplish a goal.

## Y

**YAML**
YAML Ain't Markup Language, a human-readable data serialization language commonly used for configuration files.
