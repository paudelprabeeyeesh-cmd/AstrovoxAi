# Support & Feedback

We're here to help! Choose the right channel for your needs.

## Support Channels

### GitHub Issues

**Best for**: Bug reports, feature requests, technical questions

- [Open an Issue](https://github.com/astrovox/astrovox/issues)
- Search existing issues before creating a new one
- Use issue templates for bug reports and feature requests
- Provide minimal reproduction for bugs

### GitHub Discussions

**Best for**: General questions, ideas, community chat

- [Join Discussions](https://github.com/astrovox/astrovox/discussions)
- Q&A category for usage questions
- Ideas category for feature proposals
- Show and tell for community projects

### Email Support

**Best for**: Security issues, sensitive data, enterprise support

- General support: support@astrovox.ai
- Security issues: security@astrovox.ai
- Enterprise inquiries: enterprise@astrovox.ai
- Partnership inquiries: partnerships@astrovox.ai

### Discord Community

**Best for**: Real-time chat, quick help, community bonding

- [Join Discord](https://discord.gg/astrovox)
- #help channel for questions
- #showcase channel for projects
- #announcements for updates

## Feedback

We value your feedback! Help us improve Astrovox AI.

### Feature Requests

1. Check [existing issues](https://github.com/astrovox/astrovox/issues) to avoid duplicates
2. Use the feature request template
3. Describe the problem you're solving
4. Propose a solution if you have one
5. Vote on issues you'd like to see implemented

### Bug Reports

Include the following information:
- Astrovox AI version
- Environment (OS, browser, Node/Python version)
- Steps to reproduce
- Expected vs actual behavior
- Screenshots or logs if applicable

### Documentation Feedback

- Found a typo? Submit a PR with the fix
- Unclear section? Open an issue with suggestions
- Missing content? Request it in Discussions

## Response Times

We aim to respond within these timeframes:

- Security vulnerabilities: 5 business days
- Critical bugs: 3 business days
- General issues: 7 business days
- Feature requests: Reviewed weekly
