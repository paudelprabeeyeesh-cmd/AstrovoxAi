# Stack Overflow

Ask and answer Astrovox AI questions on Stack Overflow.

## Tag

Use the `astrovox` tag for all questions.

[astrovox questions](https://stackoverflow.com/questions/tagged/astrovox)

## How to Ask

1. Search existing questions first
2. Provide a minimal reproducible example
3. Include relevant code snippets
4. Describe what you've tried
5. Be specific about your environment

## How to Answer

1. Be clear and concise
2. Provide working code examples
3. Explain the "why" not just the "how"
4. Link to documentation
5. Upvote helpful answers
