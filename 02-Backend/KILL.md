# KILL.md

## Exact triggers to kill or pivot

1. If 0 users pay after 10 real conversations → change the problem.
2. If week 4 retention <15% after 3 iterations → pivot.
3. If cost per user > $1/day and no one pays $5 → change architecture.
4. If 10 users all say "I'd use it but not pay" → change the price or the user.
5. If DAILY_BUDGET_USD is exceeded more than 3 days in a row without revenue increase → cut the feature that caused it.
