# SCALE.md

## Exact triggers to scale

1. If 5+ paying users → add the next feature only they asked for.
2. If cost per user < $0.25/day → raise the price to $9.
3. If churn <5% for 2 months → start content marketing.
4. If $500 MRR → consider hiring a contractor for support only.
5. If 3 teams sign up → build team analytics.
