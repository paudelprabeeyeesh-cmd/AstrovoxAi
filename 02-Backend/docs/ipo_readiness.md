# IPO Readiness Checklist

## 12-18 Months Before IPO

### Financial
- [ ] audited financials for 3 years
- [ ] revenue recognition policy (ASC 606)
- [ ] billing and collections automated
- [ ] financial systems (NetSuite/Workday)

### Legal
- [ ] corporate cleanup (cap table, bylaws, minutes)
- [ ] IP assignment from all employees
- [ ] customer contracts reviewed
- [ ] litigation resolved

### Compliance
- [ ] SOX compliance
- [ ] SOC2 Type II
- [ ] ISO 27001
- [ ] GDPR/CCPA compliance

### Operations
- [ ] hiring freeze 6 months before
- [ ] board of directors established
- [ ] audit committee
- [ ] investor relations function

### Technical
- [ ] security audit
- [ ] penetration test
- [ ] disaster recovery tested
- [ ] data residency verified

## Team
- [ ] CFO with public company experience
- [ ] General Counsel
- [ ] Investor Relations
- [ ] External auditor (Big 4)

## Timeline
- Month 12: Start hiring CFO
- Month 9: Begin financial audit
- Month 6: SOX compliance
- Month 3: File S-1
- Month 0: IPO
