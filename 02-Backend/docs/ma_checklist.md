# M&A Checklist

## Target Criteria
- Vertical AI startups
- Complementary tools
- Revenue: $1-10M ARR
- Growth: >100% YoY
- Team: <20 people

## Due Diligence

### Technical
- [ ] Code review
- [ ] Architecture assessment
- [ ] Security audit
- [ ] Tech stack compatibility

### Financial
- [ ] Revenue quality (recurring vs one-time)
- [ ] Gross margin
- [ ] Burn rate
- [ ] Customer acquisition cost

### Legal
- [ ] Cap table clean
- [ ] IP ownership
- [ ] Customer contracts assignable
- [ ] No litigation

### Commercial
- [ ] Customer references
- [ ] Churn rate
- [ ] NPS
- [ ] Product-market fit

## Integration Plan
- [ ] Technical integration (2 weeks)
- [ ] Customer migration (4 weeks)
- [ ] Team integration (2 weeks)
- [ ] Brand consolidation (4 weeks)

## Budget
- Target: $20-50M per acquisition
- Sources: Cash + stock
- Integration cost: $500K-$1M
