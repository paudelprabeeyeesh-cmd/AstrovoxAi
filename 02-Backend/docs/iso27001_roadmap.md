# ISO 27001 Roadmap

## Timeline: 180 days

## Phase 1: Scoping (30 days)
- Define ISMS scope
- Identify assets
- Risk assessment

## Phase 2: Implementation (90 days)
- Implement controls (Annex A)
- Document policies
- Train employees

## Phase 3: Certification (60 days)
- Select certifying body
- Stage 1 audit
- Stage 2 audit
- Certification

## Key Controls
- Access control
- Cryptography
- Physical security
- Operations security
- Communications security
- Supplier relationships
- Incident management

## Tools
- OneTrust or Vanta
- AWS Config
- AWS Security Hub

## Cost
- Certifying body: $30-50K
- Tools: $10K/mo
- Internal: 1 engineer, 2 weeks
